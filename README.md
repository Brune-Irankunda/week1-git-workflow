# Week 1 Git Workflow

## Project Description
This project is a simple recipe webpage created to demonstrate a collaborative Git and GitHub workflow.

## Technologies Used
- HTML
- CSS
- Git
- GitHub

## Setup Instructions
1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Git Workflow
- Create a feature branch for each task.
- Make changes and commit them with clear commit messages.
- Push the feature branch to GitHub.
- Create a Pull Request against `main`.
- Review and merge the Pull Request through GitHub.
- Delete the feature branch after merging.

## Project Structure
- `index.html` - Main recipe webpage
- `style.css` - Styling for the recipe webpage
- `README.md` - Project documentation
